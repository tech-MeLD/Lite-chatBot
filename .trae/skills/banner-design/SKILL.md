# Banner Design

Design banners across social, ads, web, and print formats. Generates multiple art direction options per request.

## When to Use

- User requests banner, cover, or header design
- Social media cover/header creation
- Ad banner or display ad design
- Website hero section visual design
- Event/print banner design
- Creative asset generation for campaigns

## Workflow

### Step 1: Gather Requirements

Collect via AskUserQuestion:
1. **Purpose** — social cover, ad banner, website hero, print?
2. **Platform/size** — which platform or custom dimensions?
3. **Content** — headline, subtext, CTA, logo placement?
4. **Brand** — existing brand guidelines?
5. **Style preference** — art direction style?

### Step 2: Design Options

For each art direction option:
1. Create HTML/CSS banner using exact platform dimensions
2. Apply safe zone rules (critical content in central 70-80%)
3. Max 2 typefaces, single CTA, 4.5:1 contrast ratio

### Step 3: Export

Export banners to PNG at exact platform dimensions.

| Platform | Type | Size (px) |
|----------|------|-----------|
| Facebook | Cover | 820 × 312 |

| Instagram | Story | 1080 × 1920 |
| Instagram | Post | 1080 × 1080 |
| Website | Hero | 1920 × 600 |

## Design Rules

- **Safe zones**: critical content in central 70-80%
- **CTA**: one per banner, bottom-right, min 44px height
- **Typography**: max 2 fonts, min 16px body, ≥32px headline
- **Text ratio**: under 20% for ads (Meta penalizes heavy text)
- **Print**: 300 DPI, CMYK, 3-5mm bleed
