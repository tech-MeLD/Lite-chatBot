# 更新报告

## 2026-05-08 — Tauri 桌面端 SSE 流断开 & 会话删除功能

### 问题 1：SSE 流式对话误报"连接意外断开"

**现象**：发送消息后，前端先显示"错误: 连接意外断开"，刷新页面后 AI 回复正常显示。

**根因**（两个层面）：

1. **后端**：`chat.py` 中 `yield` done 事件后立即执行 `extract_and_store()`（LLM embedding 调用），事件循环未 flush 数据就直接阻塞在 embedding 上。网络层可能将 done 数据包与连接关闭合并发送。

2. **前端**：`client.ts` 中 `ReadableStream` 读取逻辑使用 `if (done) break` 在数据处理之前判断，且按 `\n` 拆分行（非 SSE 标准的 `\n\n` 分隔），大 JSON 跨 chunk 时容易丢失事件。

**修复**：

| 文件 | 修改 |
|------|------|
| `backend/app/api/v1/chat.py` | 在 `yield` done 事件后添加 `await asyncio.sleep(0)` 主动让出事件循环 |
| `tauri-app/src/api/client.ts` | 重构 SSE 解析：先处理 `value` 再判断 `done`；使用 `\n\n` 作为 SSE 事件分隔符；循环结束后处理 buffer 残留数据 |

### 问题 2：缺少会话删除功能

**现象**：新建的对话无法删除，会话列表只增不减。

**修复**：

| 文件 | 修改 |
|------|------|
| `backend/app/api/v1/session.py` | 新增 `DELETE /sessions/{session_id}` 端点，级联删除 feedbacks → messages → session |
| `tauri-app/src/api/client.ts` | 新增 `deleteSession()` 函数；`request()` 适配 204 No Content |
| `tauri-app/src/components/SessionList.tsx` | 新增 onDelete prop；悬停显示 X 删除按钮；二次确认机制 |
| `tauri-app/src/pages/ChatPage.tsx` | 新增 `handleDelete()` 函数，删除后从列表中移除并在选中时清空消息 |
